# Campus Clinic Finder

大学生が空きコマで行けそうな病院を探し、受診時間を記録できるWeb版MVPです。

詳しい要件は [SPEC.md](./SPEC.md) を参照してください。

## 使い方

施設検索API付きのローカルサーバーを起動してブラウザから開きます。

```powershell
python server.py
```

起動後、`http://localhost:8000` を開いてください。

## 施設データ

`db` フォルダの全国CSVから、同志社大学今出川キャンパスと宮崎大学木花キャンパスを中心とした各12km圏内の病院・診療所・薬局を抽出しています。CSVを更新した場合は次のコマンドで検索用データを再生成できます。

```powershell
node scripts/build-facility-data.js
```

生成先は `data/facilities.js` です。

全国の施設を現在地から検索するSQLite DBは、次のコマンドで生成します。

```powershell
python scripts/build_facility_db.py
```

生成先は `data/facilities.sqlite3` です。`server.py` の `/api/facilities` が緯度・経度から周辺施設を検索します。

## 経路時間

OpenStreetMapの道路データとOSRM Table APIを利用し、出発地点から各施設までの往路・復路を別々に計算します。徒歩、自転車、車に対応しています。

現在はOSRMの公開デモサーバーを利用しているため、非商用のMVP・検証用途向けです。APIへのアクセスは1秒に1回以下へ制限し、同じ検索結果はブラウザのセッション内でキャッシュします。本番公開時はOSRMのセルフホストまたはSLAのある経路サービスへ切り替えてください。

## 実装済み

- 施設種別、診療科、出発時刻、戻りたい時刻、移動手段による病院・診療所・薬局検索
- 今出川キャンパス、宮崎大学木花キャンパス、端末の現在地からの検索
- 移動時間、滞在時間、費用目安、間に合いそうかの表示
- 病院詳細とGoogle Mapsリンク
- 「この病院に行く」から受診予定を作成
- Web版の手動到着/終了計測
- 費用、予約有無、待ち時間の簡易記録
- ローカルストレージ保存
- カレンダー形式の受診ログと月間サマリー
